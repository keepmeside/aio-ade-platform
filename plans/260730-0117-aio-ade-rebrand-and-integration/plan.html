Đã duyệt: Option B

Canvas: Excalidraw offline

Excalidraw MIT là canvas mặc định, file-backed trong workspace, export PNG/SVG và structured context. XYFlow chỉ thêm sau usage validation.

Đã duyệt: Excalidraw

Profile: hai loại, resolver riêng

Account là OAuth/subscription. API profile là key, base URL, model và policy, nhưng Claude và Codex phải materialize config theo hai contract khác nhau.

Pages: đang bị billing chặn

Workflow manual đã push nhưng GitHub chặn trước build vì billing/payment hoặc spending limit; Pages API trả 404. Repo chính vẫn private và không đổi visibility.

Cần chọn: sửa billing hoặc duyệt public plan repo riêng

06 / risks

Bốn rủi ro cần kiểm soát sớm.

Nếu các rủi ro này để đến cuối, test xanh giả tạo và release mới là lúc vỡ.

Stale roster state

Persistence hiện đọc JSON và chỉ normalize một phần. Phải sanitize default agent, override và model maps ở load lẫn RPC boundary.

Retained PTY runtime

Full CLI delete không được xoá nhầm generic PTY/SSH contracts. Relocate runtime tests trước, rồi kiểm tra xterm write/resize/reattach, Fable TUI và Codex flow từ desktop-owned modules.

Fable compatibility

Không thêm ANSI adapter riêng cho Fable. Giữ bytes model-blind, main-owned launch spec và fallback raw terminal khi parser phụ trợ không nhận diện được output.

Public exposure

Public repo chính để có Pages sẽ lộ toàn bộ fork. Tách plan site public hoặc dừng ở local artifact.
