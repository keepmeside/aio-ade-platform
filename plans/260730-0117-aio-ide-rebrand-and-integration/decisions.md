## Đã xác minh

- Working copy đã có remote `keepmeside/aio-ade-platform`; không cần clone đè.
- Account subsystem Claude/Codex đã tồn tại lớn, nên switcher là mở rộng seam chứ không xây từ số 0.
- `src/main/runtime/orchestration/preamble.ts` inject lệnh CLI vào terminal agent; xoá CLI mà không xoá orchestration sẽ làm worker timeout.
- `mobile/` có lockfile và roster riêng; `pnpm lint` đang truyền literal path `mobile` và reliability gates có path tới mobile/CLI.
- tldraw SDK hiện hỗ trợ React 18/19 và offline rendering, nhưng production cần trial/commercial/hobby key; hobby giữ watermark. Vì aio-ade muốn bản MIT không key và không watermark, vẫn không chọn tldraw mặc định.
- tldraw commercial/hobby key validate client-side và dùng offline; commercial/hobby không gửi dữ liệu, trial chỉ ping license-key hash theo docs. `offline.tldraw.com` là desktop-app prior art riêng; source license, document contract và agent bridge vẫn cần review trước reuse.
- CCS là MIT, có phân tách account/profile, global env, routing, quota, migration và doctor; không nên bê nguyên plaintext secret store hoặc web server.
- CCS `v8.8.1` tại commit `51e8716` lưu generic API settings plaintext. Codex không nhận generic API profile trực tiếp ngoài CLIProxy bridge, nên aio-ade chỉ lấy schema/policy ideas và phải giữ resolver riêng cho Codex.
- Upstream license (2026-08-21): `LICENSE` repo root là **MIT, Copyright (c) 2026 Lovecast Inc.** — public redistribution fork đã modify được phép nếu giữ copyright notice + license text. MIT không cấp quyền trademark nên tên "Orca" đi public trước phase 05 là exposure riêng.
- ACP (2026-08-21, theo `research/acp-generic-agent-support.md`): spec v1 stable, JSON-RPC over stdio, governance Zed + JetBrains, SDK `@agentclientprotocol/sdk` Apache-2.0 (tương thích MIT, cần NOTICE). Gemini CLI và opencode native ACP; ~39 agent trong registry. v2 còn draft và đổi diff format → bọc protocol types sau internal adapter.
- Electrobun (2026-08-21, theo `research/electrobun-migration-feasibility.md`): MIT, nhưng single maintainer với no-support policy, giữa 2.0 rewrite, thiếu safeStorage equivalent, Windows PTY chỉ có community FFI, Windows signing chưa document, OS floor cao hơn floor hiện tại của app. Full migration = rewrite → chỉ spike có gate.
- Rust + GPUI (2026-08-21, theo `research/rust-gpui-hybrid-migration.md`): `gpui` crate là **Apache-2.0** (tương thích app MIT) nhưng publish đứng yên ở 0.2.2 từ 2025-10-22 (~10 tháng), không có docs.rs, vẫn 0.x. Ecosystem có thật: 124 reverse deps, `gpui-component` 0.5.1 (Apache-2.0, 47.8k LOC, có feature `webview` qua `wry`), `gpui-terminal` 0.1.0 (MIT/Apache, 2.3k LOC). **Code editor/terminal của Zed là GPL — không dùng được cho app MIT**; chỉ `gpui` engine là Apache-2.0. Renderer hiện tại 4.940 file React/Tailwind/Monaco/xterm.js với 0 import `electron` trực tiếp → decoupled khỏi Electron API (tốt cho mọi hướng), nhưng port sang GPUI là viết lại UI. Repo hiện không có Rust và không có N-API addon; `native/` là 5 sidecar Swift/C#/Python/PowerShell.
- Tauri v2 (2026-08-21, theo `research/tauri-v2-migration-feasibility.md`): `tauri` **2.11.5** (2026-07-01), 220 version, **26.7M downloads**, license **Apache-2.0 OR MIT** (chọn MIT được), repo 110k stars push hằng ngày, Tauri Foundation đứng sau. **OS floor rộng hơn Electrobun rất nhiều: macOS 10.15+, Windows 7+**; chỉ Linux bị đẩy lên **Ubuntu 22.04** vì cần `libwebkit2gtk-4.1-dev`. Plugin chính thức đầy đủ (updater, store, stronghold, shell, single-instance, notification, dialog, fs, sql, tray, menu) và packaging/signing tốt hơn Electrobun rõ rệt (DMG, MSI+NSIS, deb, RPM, AppImage, Snapcraft, Flathub, App Store, MS Store). **Có guide chính thức "Node.js as a sidecar"** → cho phép giữ main process TypeScript hiện tại làm sidecar và migration tăng dần thay vì big-bang. Nhược điểm: vẫn webview fragmentation qua `wry` (WKWebView/WebView2/WebKitGTK), **không có safeStorage tương đương trực tiếp** (Stronghold là vault riêng, `store` không encrypt), không có preload model, và 227 file dùng `electron` API vẫn phải thay. Xếp hạng: hướng non-Electron chín nhất trong ba hướng.

## Nguyên tắc rollback

Mỗi phase một commit hoặc một chuỗi commit nhỏ có thể revert. Trước migration rebrand tạo backup marker và migration version. Không xoá legacy auth directories trước khi có test restore. Public repo chính: chỉ sau khi pre-publication gate của phase 08 pass đủ (upstream license, history secret scan, PII, workflow/runner audit, upstream endpoints inert), và owner là người flip — flip là bất khả nghịch thực tế, không có rollback sau external clone.

## Câu hỏi chưa giải quyết

Không còn câu hỏi nào chặn việc cook. Các điểm sẽ tự phát sinh quyết định trong lúc thực thi:

- **Phase 01:** kết quả history secret scan. Nếu tìm thấy secret upstream không rotate được → chạy nhánh contingency đã duyệt (báo upstream + squashed public mirror song song).
- **Phase 09:** xoá thật `serve` hay không, dựa trên việc remote development có thành product requirement.
- **Phase 11:** verdict Tauri GO/NO-GO. Nếu bundle size xấu >10% (khả năng cao vì Node sidecar) → cần quyết định user riêng, không auto-NO-GO.
- **Sau khi có cert:** bật signing + notarization, rồi mới bật auto-update.
