## Shortlist

1. Account/API profile split + secure launch resolver (CCS).
2. Hook-driven lifecycle and permission reply (Maverick, nodeterm).
3. Global unread/needs-you centre and pane status grammar (cmux, Termdeck).
4. Commitlint-aware prompts and safe commit hook (opencommit).
5. Code-review graph as optional MCP context provider (Code Review Graph).
6. Excalidraw-first workspace board; XYFlow only after topology demand; tldraw license gate.
